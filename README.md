# 대화 리와인드

카카오톡·디스코드 대화 내보내기 파일을 올리면 브라우저 안에서만 분석해서
누가 제일 말이 많았는지, 자주 쓴 이모지, 시간대별/요일별 활동 패턴을 보여주는
정적 웹 도구입니다.

- 순수 HTML/CSS/JS 단일 파일 (`index.html`), 빌드나 서버 필요 없음
- 파일은 어디로도 전송되지 않고 전부 로컬(브라우저)에서 처리됨
- 지원 형식: 카카오톡 PC/모바일 내보내기(.txt), 디스코드 DiscordChatExporter 내보내기(.txt/.csv)

## 사용법

`index.html`을 브라우저로 그냥 열면 됩니다. (더블클릭 또는 로컬 서버 아무거나 사용)

```
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```
